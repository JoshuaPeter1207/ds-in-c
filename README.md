# DSA in C

This is where I'm documenting my journey of learning Data Structures and Algorithms in C.

I'm not here to just solve problems and move on. I want to understand how things work, how to approach a problem, and how to improve my solution when there's a better way to do it.

## What I'm Working On

- Arrays
- Linked Lists
- Stacks and Queues
- Trees
- Searching and Sorting
- Recursion

## How I Approach Problems

For the problems I solve, I try to understand:

- How I arrived at the solution
- Why the approach works
- Time and space complexity
- Edge cases I need to handle
- What I could have done better

I'll also document the mistakes I make and the things I learn along the way, because getting a solution accepted isn't the same as fully understanding it.

## Language

- C

## The Goal

Get better at breaking down problems, writing cleaner code, recognising patterns, and eventually solving unfamiliar problems independently.

One problem at a time. The focus is on understanding, not just counting how many I've solved.
